Store text on the key, then press the button to type it

Served from localhost or HTTPS. The text travels in user.id, the one create() field a page can fill with arbitrary bytes that reaches the authenticator untouched.
The key stores it in RAM: unplugging erases it, so write it again after every plug-in.

USB keyboards send key positions, not characters — the computer decides what character each position produces. The key therefore has to be told which layout to aim at, and it must be the layout of the machine that will receive the typing.
